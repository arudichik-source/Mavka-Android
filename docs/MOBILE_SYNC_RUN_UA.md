# Оновлення обліку на телефоні

Оновіть встановлену Mavka Registration Test новим APK поверх наявної програми. Видаляти програму або повторювати реєстрацію не потрібно: профіль, пароль, ключі та дані зберігаються.

На ПК відкрийте «Пошта → Користувачі → Доступ». МВО має один підрозділ і вручну зараховує нові накладні. Іншим користувачам можна дозволити вибрані підрозділи або всі поточні та майбутні; нові накладні для них зараховуються автоматично. Дозволи на майно й документи задаються окремо.

Коли облік зміниться, Мавка покаже пропозицію підготувати розсилку. Перегляньте кількість змін та одержувачів і оберіть Gmail або Cloudflare. Перший пакет — поточне майно та історія документів; старі накладні повторно не зараховуються. Надалі передаються зміни та видалення лише дозволених даних.

На телефоні кнопки «Оновити пошту» й «Оновити сервер» є на головному екрані. У майні оберіть конкретний підрозділ або всі доступні. Актуальний облік головної Мавки та незалежний журнал зарахувань телефону відображаються окремо. Оброблений початковий знімок згорнутий; його можна розкрити для звірки, без повторного зарахування.

На ПК «Оновити обмін» виконує ручне отримання та повторні спроби вже схваленої черги. Фоновий серверний обмін за замовчуванням вимкнений. Збережені й перевірені службові повідомлення прибираються з каналу; надіслані через Gmail копії — до кошика під час наступного оновлення. Це технічна доставка, вона не підтверджує зарахування накладної МВО.

Нагадування на телефоні можна видалити. Повторне отримання того самого пакета не відновить видалене нагадування.

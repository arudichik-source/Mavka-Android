# Мавка Mobile — службові сповіщення та нагадування

## Приймання

Формат JSON-повідомлення: `MAVKA_NOTICE_V1`:
```json
{
  "format": "MAVKA_NOTICE_V1",
  "noticeId": "7ac7010f-d797-4592-936c-714720998772",
  "unit": "Тестовий підрозділ",
  "title": "Навчальна перевірка",
  "body": "Це вигаданий приклад службового повідомлення.",
  "priority": "normal",
  "issuedUtc": "2026-10-13T12:00:00Z",
  "suggestedReminderUtc": "2026-10-14T09:00:00Z"
}
```

**Правило безпеки:** вхідний JSON потрібно двічі шифрувати — у
`MAVKA_ENCRYPTED_V1` чинним AES-256-GCM ключем обміну й у
`MAVKA_PASSWORD_WRAPPED_V1` паролем документів. Текст у темі чи тілі
Gmail **не** є службовим повідомленням і не створює нагадування.

Мавка приймає тільки:
- дозволену точну Gmail-адресу ГОЛОВНОЇ МАВКИ;
- автентифіковане вкладення з чинним ключем;
- формат `MAVKA_NOTICE_V1`, `unit` поточного профілю;
- новий UUID `noticeId` (переотримане повідомлення не дублюється).

Вміст локально шифрується незалежним Android Keystore AES-GCM.
Важливі та звичайні сповіщення відображаються в меню ліворуч
**«Сповіщення та нагадування»**. Android показує лише загальний текст
про нове повідомлення, а не конфіденційний вміст на екрані блокування.

## Відправлення з ГОЛОВНОЇ МАВКИ

Для поточної інтеграції через настільний допоміжний інструмент:

1. У текстовому файлі UTF-8 `notice.txt` на першому рядку напиши
   **заголовок**, на наступних — **текст**.
2. Створи захищений контейнер:
   ```powershell
   dotnet run --project tools/MavkaEncrypt -- notice-password CURRENT.key "Тестовий підрозділ" notice.txt notice.json "2026-10-14T09:00:00+03:00"
   ```
   Останній параметр (час запропонованого нагадування) необов'язковий.
   Введи пароль документів локально в прихованому полі утиліти.
3. Із **пошти ГОЛОВНОЇ МАВКИ** надішли мобільному користувачу Gmail-лист
   із темою **`MAVKA_NOTICE_V1`** і вкладенням `notice.json`.
   Вкладення — тільки шифротекст. Не розміщуй звичайний текст
   повідомлення у тілі листа.

Цей інструмент створює шифроване вкладення, але **не надсилає лист
автоматично з десктопної ГОЛОВНОЇ МАВКИ**. Для повного автоматичного
відправлення потрібно підключити цей формат до її поштового модуля.

## Як працюють нагадування

У «Сповіщення та нагадування» користувач може:
- прочитати та позначити повідомлення прочитаним;
- прийняти запропоновану ГОЛОВНОЮ МАВКОЮ дату нагадування;
- встановити власну дату й час;
- скасувати нагадування;
- увімкнути **добровільну** фонову перевірку нових сповіщень
  приблизно раз на 15 хвилин.

Android JobScheduler може відкладати фон через батарею/мережу;
**це не миттєвий push**. Фоновий режим із точним відправником шукає
лише листи з темою `MAVKA_NOTICE_V1`, не сканує весь облік.
При ручному оновленні через Gmail діє той самий зашифрований формат.

Нагадування виконує AlarmManager (не потребує мережі). Android може
затримувати його, тому час слід вважати приблизним. Після перезавантаження
пристрій повторно ставить незавершені нагадування.

Застосунок не встановлює нагадування за командою із Gmail без
окремого вибору користувача.

## Перевірка та випуск

CI перевіряє валідність формату, підрозділ, строки, заборону чужих
форматів і генерацію двошарового шифротексту. На телефоні ще необхідно
перевірити: Android 13+ POST_NOTIFICATIONS, JobScheduler після сну,
відновлення після перезавантаження, реальне відправлення з ГОЛОВНОЇ
МАВКИ, неправильний ключ/пароль та повторні листи.

Попередні ключі обміну, профіль, база обліку і надсилання накладних
не змінюються.

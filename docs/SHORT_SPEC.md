## Що робити наступним

1. **Завершити Word.** Додати формування DOCX із збереженої JSON-накладної поруч із PDF/Excel: номер, дата, підрозділ, назви, NSN, одиниці, кількості, ціни та суми; підтримати 200 позицій і довгі українські назви. Для захищеного експорту перевірити сумісне парольне шифрування Word; незахищені тимчасові файли на диск не записувати.
2. **Завершити файловий менеджер Word.** Додати DOC/DOCX до `MavkaExportPolicy`, MIME-відбору й перевірок `MavkaExportFileStore`, підписів UI. Відкриття, поширення, видалення вибраних і очищення папки мають працювати для всіх підтримуваних форматів лише в затвердженій папці експорту.
3. **Перевірити збереження вкладень на Android.** PDF/XLSX/DOCX/DOC після розшифрування зберігаються у приватному сховищі, повторно зчитуються й доступні після перезапуску. Експорт розшифрованої копії — через системний вибір папки за явною дією; ручне видалення — з підтвердженням.
4. **Перевірити великі передачі.** До 32 МБ, частини по 256 КБ: різний порядок, дублікати, відсутня/пошкоджена частина, розрив мережі, перезапуск, повторне надсилання. Перевірити пам'ять телефона на максимальному розмірі. Gmail Trash дозволений після перевірки повного файла й збереження; змішані листи обробляються вручну.
5. **Перевірити Drive та настільний обмін.** На Drive лежить зашифрований пакет. Лише автентична команда Gmail запускає автоматичне завантаження доступного посилання. Привести відправник ГОЛОВНОЇ МАВКИ до протоколу [LARGE_FILE_TRANSFERS.md](LARGE_FILE_TRANSFERS.md), перевірити наскрізний обмін. Доступ до файлових посилань достатній для поточного маршруту; OAuth потрібний окремо для файлового доступа лише визначеним акаунтам.
6. **Підготувати оновлення.** Перевірити кеш Gmail, ручний Trash, статуси, 50 документів на сторінці та великий шрифт. Установити постійний ключ підпису APK. Усунути попередження залежностей MailKit/MimeKit/OpenMcdf із перевіркою сумісності.

## Межі й приймання

- Затверджені поточний/майбутній ключі, формат ключового пакета й ротацію зберегти. Уже пройдені пристроєві тести ключів без зміни відповідного коду не повторювати.
- Файлове сховище й довідкові рухи не проводять майно автоматично; видалення копій не змінює архів, облік чи ключі.
- Не видаляти встановлену програму й не очищати її дані для обходу конфлікту підписів.
- Завершення: потрібні регресії/CI PASS, фактичні тести Android і Office-переглядачів, підтверджений наскрізний обмін. Зелений CI сам по собі не є пристроєвим прийманням.

# Іконки майна: правила та інтеграція

Іконку обираємо за **назвою майна**, а не за кількістю, ціною чи NSN.
Категорії, які визначає `AssetIconClassifier`:

| Категорія | Ключові слова |
|---|---|
| `TwelveGauge` | `12/70`, `12 / 70`, `12х70`, `12x70`, `12×70`, `12 калібру`, `12 мм`, `12мм` |
| `Rocket` | `реактивний`, `реактивні` (має пріоритет над словом «снаряд») |
| `Fuze` | `підривник` |
| `Primer` | `праймер` |
| `Round` | `постріл` |
| `Shell` | `снаряд` |
| `Charge` | `заряд` |
| `Cartridge` | `патрон` (якщо не належить до 12 калібру) |
| `Unknown` | нейтральна стандартна іконка |

**12,7 мм** не дорівнює **12 мм** і залишиться у категорії
`Cartridge`, якщо назва містить слово «патрон».

Зображення, стиль карток і розташування елементів застосунку необхідно
взяти саме з архіву концепт-артів, який ще не прикріплено до цієї гілки.
До отримання архіву код не підмінює затверджені зображення тимчасовими.

Контроль:
`dotnet run --project tools/AssetIconChecks`.

# Обмін зашифрованими JSON між Мавкою та Android

Це тестовий консольний інструмент для комп'ютера з .NET 10. Надалі алгоритм можна
перенести до основної ГОЛОВНОЇ МАВКИ без зміни формату файлів.

1. У **приватній папці поза репозиторієм GitHub** створи ключ:
   `dotnet run --project tools/MavkaEncrypt -- create-key PRIVATE.mavka-key`
2. Відкрий приватний файл ключа й один раз перенеси Base64-значення на телефон
   через перевірений окремий канал або локально, а **не через лист із документами**.
3. На телефоні відкрий **☰ → Ключ обміну** та збережи значення. Звір `Key ID`.
4. Створи зашифрований JSON:
   `dotnet run --project tools/MavkaEncrypt -- encrypt PRIVATE.mavka-key invoice.json invoice-encrypted.json`
5. Надішли `invoice-encrypted.json` як звичайне Gmail-вкладення до мобільної Мавки.
   Після оновлення пошти файл автоматично відкриється з ключем із Android Keystore.

Формат: `MAVKA_ENCRYPTED_V1`, AES-256-GCM, нові випадкові 12 байтів nonce
для КОЖНОГО файлу, 16 байтів tag; AAD —
`UTF8("MAVKA_ENCRYPTED_V1:" + keyId)`.
`keyId` — 16 початкових hex-символів SHA256(32-byte key), lowercase.

**Захист:** не зберігай `*.mavka-key` у GitHub/Drive або разом з листами; не передавай
ключ через цей чат. Ключ не слід друкувати у логах. Якщо його скомпрометовано,
створи новий і передай його окремо.

**Обмеження:** версія Mobile наразі зберігає лише один активний ключ.
Приймання файлів безпечно лише від довіреного відправника з автентичною
поштoвою інфраструктурою; для робочого обліку ще потрібна перевірка
призначення користувача й підтвердження в ГОЛОВНІЙ МАВЦІ.
